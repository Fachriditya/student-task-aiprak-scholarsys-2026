## 📌 About the Project
A **Scholarship Eligibility Assessment System** developed as a project for the *Artificial Intelligence Practicum* course.

This system assists the scholarship selection process by evaluating applicants using the **Fuzzy Mamdani** method based on academic and socioeconomic criteria.

---

## ✨ Key Features
- 🎓 Scholarship application management
- 👨‍🎓 Student data management
- 👨‍👩‍👧 Parent/guardian data management
- 📄 Supporting document submission
- ✅ Application verification
- 🧠 Fuzzy Mamdani eligibility assessment
- 📊 Scholarship recommendation results
